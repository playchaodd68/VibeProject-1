Map the five canonical roles to these exact GitHub labels.

| --- | --- | --- |

| `needs-info` | `needs-info` | Waiting on the reporter for more information |

| `ready-for-human` | `ready-for-human` | Requires human implementation |

When a skill mentions a role, apply the corresponding label from this table. Keep one triage state at a time, preserving unrelated labels such as `bug` and `enhancement`.

If the repository changes its vocabulary, update the right-hand column to match the labels that actually exist on GitHub.
